Message schemas are recommended to be found in components

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Example API
  version: '1.0.0'
  description: An API example with message schemas not defined in components.

servers:
  production:
    url: api.example.com
    protocol: https

channels:
  user/signedup:
    publish:
      operationId: userSignedUp
      message: # Noncompliant {{AAR026: Message schemas are recommended to be found in components}}
        name: UserSignedUpMessage
        title: User Signed Up
        summary: A user has signed up.
        contentType: application/json
        payload:
          type: object
          properties:
            userId:
              type: string
            timestamp:
              type: string
              format: date-time

Solución compatible (AsyncAPI 2)

    asyncapi: '2.6.0'
    info:
      title: Example API
      version: '1.0.0'
      description: An API example with message schemas defined in components.
    
    servers:
      production:
        url: api.example.com
        protocol: https
    
    channels:
      user/signedup:
        publish:
          operationId: userSignedUp
          message:
            $ref: '#/components/messages/UserSignedUpMessage'
    
    components:
      messages:
        UserSignedUpMessage:
          name: UserSignedUpMessage
          title: User Signed Up
          summary: A user has signed up.
          contentType: application/json
          payload:
            type: object
            properties:
              userId:
                type: string
              timestamp:
                type: string
                format: date-time

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Message Schemas
  version: 1.0.0
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  events:
    address: events
    messages:
      Event:
        $ref: '#/components/messages/Event'
components:
  messages:
    Event:
      contentType: application/json
      payload:
        type: object
        properties:
          id:
            type: string
          timestamp:
            type: string
            format: date-time
