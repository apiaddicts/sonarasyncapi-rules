El nombre del channel — la clave del mapa channels en AsyncAPI 2.x, o el campo address del channel en AsyncAPI 3.x+ — debe seguir la convención de nomenclatura de topics Kafka:

<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]
  • Exactamente 5 segmentos obligatorios (cod_poaps, classification, domain, origin, scope), separados por puntos (.).
  • Puede añadirse un 6º segmento opcional version (normalmente solo ante breaking changes).
  • Cada segmento puede contener letras minúsculas y dígitos; los guiones (-) solo se permiten como separador interno dentro de un segmento (sin guiones al inicio, al final, ni dobles).
  • No se permiten guiones bajos (_) en ninguna parte del nombre del channel.

Ejemplo Noncompliant (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca_registro:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Solución Compliant (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.cmd.alumnos.registro-bonificacion.beca:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Ejemplo Noncompliant (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Scholarship API
  version: 1.0.0
channels:
  scholarshipRegistration:
    address: beca_registro
    messages:
      Registration:
        payload: {type: object}

Solución Compliant (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Scholarship API
  version: 1.0.0
channels:
