En el contexto Kafka, el protocol de cada servidor declarado en la sección servers debe ser kafka o kafka-ssl. Cualquier otro protocolo, como https, wss o amqp, no está permitido.

Ejemplo de código no conforme (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: My Async API
  version: '1.0.0'
servers:
  production:
    url: broker.example.com:9092
    protocol: https   # Noncompliant {{AAR064: The server protocol must be 'kafka' or 'kafka-ssl'}}
    description: Production server
channels:
  user-events: {}

Solución conforme (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: My Async API
  version: '1.0.0'
servers:
  production:
    url: broker.example.com:9092
    protocol: kafka-ssl
    description: Production server
channels:
  user-events: {}
