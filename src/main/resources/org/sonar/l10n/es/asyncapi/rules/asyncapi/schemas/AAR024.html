Cada mensaje debe declarar un 'contentType' salvo que sea un mensaje Avro (detectado automáticamente mediante 'schemaFormat').

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: No Validation
  version: '1.0.0'
servers:
  production:
    url: 'api.example.com'
    protocol: 'wss'
channels:
  orders:
    subscribe:
      operationId: receiveOrder
      message: # Noncompliant {{AAR024: Cada mensaje debe declarar un 'contentType' salvo que sea un mensaje Avro}}
        payload:
          type: object

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Message Validation
  version: '1.0.0'
servers:
  production:
    url: 'api.example.com'
    protocol: 'wss'
channels:
  orders:
    subscribe:
      operationId: receiveOrder
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            orderId:
              type: string
