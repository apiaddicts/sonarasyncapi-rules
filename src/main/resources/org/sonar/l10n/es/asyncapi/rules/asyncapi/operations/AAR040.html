El servidor del channel debe definirse en el objeto de servidores

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Swagger Petstore
  version: '1.0.0'
servers:
  production:
    url: 'https://api.petstore.com'
    protocol: 'https'
channels:
  /pets:
    description: Canal de comunicación para operaciones relacionadas con mascotas
    servers:
      - unknown # Noncompliant {{AAR040: El channel referencia un servidor que no está definido en el objeto 'servers'.}}
    subscribe:
      operationId: receivePets
      message:
        contentType: application/json
        payload:
          type: object

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Swagger Petstore
  version: '1.0.0'
servers:
  production:
    url: 'https://api.petstore.com'
    protocol: 'https'
channels:
  /pets:
    description: Canal de comunicación para operaciones relacionadas con mascotas
    servers:
      - production
    subscribe:
      operationId: receivePets
      message:
        contentType: application/json
        payload:
          type: object

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Invalid Server Reference
  version: '1.0.0'
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  notifications:
    address: notifications
    servers:
      - unknown # Noncompliant {{AAR040: El channel referencia un servidor que no está definido en el objeto 'servers'.}}
    messages:
      Notification:
        payload:
          type: object
operations:
  SendNotification:
    action: send
    channel:
      $ref: '#/channels/notifications'
    messages:
      - $ref: '#/channels/notifications/messages/Notification'

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Valid Server Reference
  version: '1.0.0'
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  notifications:
    address: notifications
    servers:
      - production
    messages:
      Notification:
        payload:
          type: object
operations:
  SendNotification:
    action: send
    channel:
      $ref: '#/channels/notifications'
    messages:
      - $ref: '#/channels/notifications/messages/Notification'
