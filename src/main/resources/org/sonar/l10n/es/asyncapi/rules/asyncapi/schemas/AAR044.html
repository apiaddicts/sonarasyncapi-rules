Los registros Avro deben declarar un namespace para evitar colisiones de nombres y permitir la evolución del esquema entre diferentes servicios y equipos.

Ejemplo de código no compatible (AsyncAPI 2)

message:
  schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
  payload:
    type: record
    name: OrderValue
    fields:
      - name: id
        type: string

Solución compatible (AsyncAPI 2)

message:
  schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
  payload:
    type: record
    name: OrderValue
    namespace: org.example.orders
    fields:
      - name: id
        type: string

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Required
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema: # Noncompliant {{AAR044: El registro Avro debe tener el campo namespace definido}}
            type: record
            name: OrderValue
            fields:
              - name: id
                type: string

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Required
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema:
            type: record
            name: OrderValue
            namespace: org.example.orders
            fields:
              - name: id
                type: string
