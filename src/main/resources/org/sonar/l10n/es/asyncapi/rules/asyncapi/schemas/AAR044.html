Los registros Avro deben declarar un namespace para evitar colisiones de nombres y permitir la evolución del esquema entre diferentes servicios y equipos.

Ejemplo Noncompliant (AsyncAPI 2)

message:
  schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
  payload:
    type: record
    name: OrderValue
    fields:
      - name: id
        type: string

Solución Compliant (AsyncAPI 2)

message:
  schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
  payload:
    type: record
    name: OrderValue
    namespace: org.example.orders
    fields:
      - name: id
        type: string
