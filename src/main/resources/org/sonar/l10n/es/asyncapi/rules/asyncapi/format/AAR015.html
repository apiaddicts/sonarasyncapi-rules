La API debe indicar el contacto en el objeto info

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info: # Noncompliant {{AAR015: El objeto 'info' debe contener una sección 'contact'.}}
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
channels:
  /pets: {}

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
  contact:
    name: hola
    email: enrgomez2002@gmail.com
    url: https://support.example.com
channels:
  /pets: {}
