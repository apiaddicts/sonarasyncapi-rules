Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: "2.0.0"
info:
  title: Bad API
  version: "1.0.0"
components:
  messages:
    someMessage:
      payload:
        type: string
      headers:
        type: object
      examples: # Noncompliant {{Todos los ejemplos del objeto message deben seguir los esquemas de payload y headers}}
        - payload: 2137
          headers: someHeader

Solución compatible (AsyncAPI 2)

asyncapi: "2.0.0"
info:
  title: Good API
  version: "1.0.0"
components:
  messages:
    someMessage:
      payload:
        type: string
      headers:
        type: object
      examples:
        - payload: foobar
          headers:
            someHeader: someValue

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Message Examples
  version: '1.0.0'
servers:
  default:
    host: api.example.com
    protocol: wss
channels:
  users:
    address: users
    messages:
      UserSignup:
        payload:
          type: object
          properties:
            id:
              type: string
            email:
              type: string
        examples:
          - name: user-signup-example
            payload:
              id: '123'
              email: user@example.com
