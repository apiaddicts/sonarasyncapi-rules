Cuando un campo Avro usa un tipo union nullable (ej. ["null", "string"]), debe definir default: null. Sin un valor predeterminado null, los consumidores desplegados antes de que el campo fuera añadido fallarán al deserializar mensajes.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: description
      type:
        - "null"
        - string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: description
      type:
        - "null"
        - string
      default: null
