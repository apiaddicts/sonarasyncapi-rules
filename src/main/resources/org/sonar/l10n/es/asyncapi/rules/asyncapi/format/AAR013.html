No puede haber dos operaciones únicas (OperationID) que sean iguales

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
channels:
  /pets:
    description: Canal para operaciones relacionadas con mascotas.
    subscribe:
      operationId: hola
      summary: Operación para recibir la lista de mascotas.
      message:
        contentType: application/json
        payload:
          type: array
          items:
            type: object
            properties:
              id:
                type: string
                description: ID de la mascota.
              name:
                type: string
                description: Nombre de la mascota.
              species:
                type: string
                description: Especie de la mascota.
    publish: # Noncompliant {{AAR013: No puede haber dos operaciones únicas que sean iguales}}
      operationId: hola
      summary: Operación para crear una nueva mascota.
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            id:
              type: string
              description: ID de la mascota.
            name:
              type: string
              description: Nombre de la mascota.
            species:
              type: string
              description: Especie de la mascota.

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Duplicate IDs
  version: 1.0.0
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  events1:
    address: events1
    messages:
      Event:
        payload:
          type: object
  events2:
    address: events2
    messages:
      Event:
        payload:
          type: object
operations:
  PublishEvent:
    action: send
    channel:
      $ref: '#/channels/events1'
    operationId: publishEvent
  PublishEvent2: # Noncompliant {{AAR013: No puede haber dos operaciones únicas que sean iguales}}
    action: send
    channel:
      $ref: '#/channels/events2'
    operationId: publishEvent

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Unique IDs
  version: 1.0.0
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  user-events:
    address: user/events
    messages:
      UserEvent:
        payload:
          type: object
  order-events:
    address: order/events
    messages:
      OrderEvent:
        payload:
          type: object
operations:
  PublishUserEvent:
    action: send
    channel:
      $ref: '#/channels/user-events'
    operationId: publishUserEvent
  PublishOrderEvent:
    action: send
    channel:
      $ref: '#/channels/order-events'
    operationId: publishOrderEvent
