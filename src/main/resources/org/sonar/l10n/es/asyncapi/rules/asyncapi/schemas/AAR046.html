Los registros Avro deberían incluir un campo doc a nivel de registro para describir el propósito del esquema.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  doc: "Representa un pedido realizado en el sistema"
  fields:
    - name: id
      type: string
