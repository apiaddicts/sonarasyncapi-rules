Los campos Avro deberían incluir un atributo doc para describir el propósito de cada campo.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string
      doc: "El identificador único del pedido"
