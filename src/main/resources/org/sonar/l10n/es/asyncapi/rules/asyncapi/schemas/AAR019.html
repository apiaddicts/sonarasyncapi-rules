El identificador debe estar definido

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: ID Schemas
  version: '1.0.0'
servers:
  production:
    url: 'api.example.com'
    protocol: 'wss'
channels:
  users:
    subscribe:
      operationId: receiveUser
      message:
        contentType: application/json
        payload: # Noncompliant {{AAR019: El documento AsyncAPI debe definir un campo 'id'.}}
          type: object
          properties:
            name:
              type: string

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: ID Schemas
  version: '1.0.0'
servers:
  production:
    url: 'api.example.com'
    protocol: 'wss'
channels:
  users:
    subscribe:
      operationId: receiveUser
      message:
        contentType: application/json
        payload:
          type: object
          properties:
            id:
              type: string
            name:
              type: string
