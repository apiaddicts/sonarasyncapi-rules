Toda operación debe estar identificada por un nombre en camelCase.

En AsyncAPI 2.x ese nombre es el campo operationId de la operación. AsyncAPI 3.x eliminó ese campo, por lo que el nombre es la clave de la operación en el mapa operations.

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Mi API Asíncrona
  version: '1.0.0'
channels:
  pet/created:
    subscribe:   # Noncompliant {{AAR051: El operationId debe estar presente y seguir la convención de nomenclatura camelCase}}
      summary: Recibe eventos de mascota creada.
      message:
        payload:
          type: object
  pet/updated:
    publish:
      operationId: on_pet_updated # Noncompliant {{AAR051: El operationId debe estar presente y seguir la convención de nomenclatura camelCase}}
      summary: Publica eventos de mascota actualizada.
      message:
        payload:
          type: object

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Mi API Asíncrona
  version: '1.0.0'
channels:
  pet/created:
    subscribe:
      operationId: solicitarBeca
      summary: Recibe eventos de mascota creada.
      message:
        payload:
          type: object
  pet/updated:
    publish:
      operationId: onPetUpdated
      summary: Publica eventos de mascota actualizada.
      message:
        payload:
          type: object

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Mi API Asíncrona
  version: '1.0.0'
channels:
  petCreated:
    address: pet/created
    messages:
      PetCreated:
        payload:
          type: object
operations:
  OnPetCreated: # Noncompliant {{AAR051: El operationId debe estar presente y seguir la convención de nomenclatura camelCase}}
    action: receive
    channel:
      $ref: '#/channels/petCreated'
    messages:
      - $ref: '#/channels/petCreated/messages/PetCreated'
  on_pet_deleted: # Noncompliant {{AAR051: El operationId debe estar presente y seguir la convención de nomenclatura camelCase}}
    action: receive
    channel:
      $ref: '#/channels/petCreated'

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Mi API Asíncrona
  version: '1.0.0'
channels:
  petCreated:
    address: pet/created
    messages:
      PetCreated:
        payload:
          type: object
operations:
  onPetCreated:
    action: receive
    channel:
      $ref: '#/channels/petCreated'
    messages:
      - $ref: '#/channels/petCreated/messages/PetCreated'
  onPetDeleted:
    action: receive
    channel:
      $ref: '#/channels/petCreated'
