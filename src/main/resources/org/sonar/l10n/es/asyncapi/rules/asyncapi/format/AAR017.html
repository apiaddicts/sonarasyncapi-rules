El objeto license debe tener el campo url

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
  license: # Noncompliant {{AAR017: El objeto de licencia debe tener el campo URL}}
    name: Apache 2.0
channels:
  /pets: {}

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
  license:
    name: Apache 2.0
    url: https://www.apache.org/licenses/LICENSE-2.0.html
channels:
  /pets: {}
