El nombre del channel — la clave del mapa channels en AsyncAPI 2.x, o el campo address del channel en AsyncAPI 3.x+ — sigue el patrón de nomenclatura corporativo:

<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]

El segundo segmento (classification) debe ser uno de los siguientes:

  • cdc — Change Data Capture.
  • cmd — Comando que desencadena modificación en el dominio.
  • sys — Topic interno del sistema, no destinado a consumo público.

Ejemplo Noncompliant (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.evt.alumnos.registro-bonificacion.beca:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Solución Compliant (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.cmd.alumnos.registro-bonificacion.beca:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object
