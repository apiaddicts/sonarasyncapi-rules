El namespace de un schema Avro con nombre (record, enum o fixed) es obligatorio y debe seguir el patrón corporativo: org.madrid.<cod_poaps>.<classification>.<domain> para schemas de aplicación, o org.madrid.common.<domain> para schemas de uso común compartidos a través del repositorio eda_kafka_esquemas. Cada segmento puede contener letras minúsculas, dígitos, guiones y guiones bajos. Un schema que omite el namespace, o cuyo namespace no cumple el patrón, es noncompliant.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.madrid.p001.core.orders
  fields:
    - name: id
      type: string

payload:
  type: record
  name: OrderValue
  namespace: org.madrid.common.orders
  fields:
    - name: id
      type: string

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Pattern
  version: '1.0.0'
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema: # Noncompliant {{AAR052: El namespace Avro debe seguir el patrón corporativo: org.madrid.<cod_poaps>.<classification>.<domain> para esquemas de aplicación, u org.madrid.common.<domain> para esquemas comunes}}
            type: record
            name: OrderValue
            namespace: org.example.orders
            fields:
              - name: id
                type: string

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Pattern
  version: '1.0.0'
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema:
            type: record
            name: OrderValue
            namespace: org.madrid.p001.core.orders
            fields:
              - name: id
                type: string
