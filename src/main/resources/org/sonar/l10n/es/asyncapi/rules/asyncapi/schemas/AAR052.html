El namespace de un schema Avro de tipo record debe seguir el patrón corporativo: org.madrid.<cod_poaps>.<classification>.<domain> para schemas de aplicación, o org.madrid.common.<domain> para schemas de uso común compartidos a través del repositorio eda_kafka_esquemas. Cada segmento puede contener letras minúsculas, dígitos, guiones y guiones bajos.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.madrid.p001.core.orders
  fields:
    - name: id
      type: string

payload:
  type: record
  name: OrderValue
  namespace: org.madrid.common.orders
  fields:
    - name: id
      type: string
