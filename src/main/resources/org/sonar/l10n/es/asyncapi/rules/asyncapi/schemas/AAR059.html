El campo name de cada record Avro debe estar en CamelCase con la primera letra mayúscula (ej.: SolicitudComunicacion, ResultadoComunicacionMail). Esto aplica tanto al record de nivel superior como a cualquier record anidado dentro de fields[].type (como tipo anidado directo, dentro de una unión, dentro de items de un array, o dentro de values de un map). AAR048 ya valida que los nombres Avro usen solo caracteres válidos, pero no exige esta convención de mayúsculas/minúsculas.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: SolicitudComunicacion
  namespace: org.example.orders
  fields:
    - name: resultado
      type:
        type: record
        name: resultado_comunicacion_mail # Noncompliant - el nombre del record anidado no está en CamelCase
        fields:
          - name: estado
            type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: SolicitudComunicacion
  namespace: org.example.orders
  fields:
    - name: resultado
      type:
        type: record
        name: ResultadoComunicacionMail
        fields:
          - name: estado
            type: string
