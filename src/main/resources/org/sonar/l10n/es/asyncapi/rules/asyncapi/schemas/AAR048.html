Los nombres Avro (de registros y campos) deben comenzar con [A-Za-z_] y a continuación contener únicamente [A-Za-z0-9_]. Los nombres que comienzan con dígitos o que contienen guiones son inválidos y provocarán errores al analizar el esquema.

Ejemplo de código no compatible (AsyncAPI 2)

payload:
  type: record
  name: 0-invalid-record
  namespace: org.example.orders
  fields:
    - name: order-id
      type: string

Solución compatible (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: orderId
      type: string

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Name Nomenclature
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema: # Noncompliant {{AAR048: El nombre Avro debe empezar con una letra o guion bajo, y solo puede contener letras, números y guiones bajos}}
            type: record
            name: 0-invalid-record
            namespace: org.example.orders
            fields:
              - name: id
                type: string

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Name Nomenclature
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema:
            type: record
            name: OrderValue
            namespace: org.example.orders
            fields:
              - name: orderId
                type: string
