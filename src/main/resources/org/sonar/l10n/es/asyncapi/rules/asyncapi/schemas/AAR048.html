Los nombres Avro (para registros y campos) deben comenzar con [A-Za-z_] y contener solo [A-Za-z0-9_]. Los nombres que comienzan con dígitos o contienen guiones son inválidos.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: 0-invalid-record
  namespace: org.example.orders
  fields:
    - name: order-id
      type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: orderId
      type: string
