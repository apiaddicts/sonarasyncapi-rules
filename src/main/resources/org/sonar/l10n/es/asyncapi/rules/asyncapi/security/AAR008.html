Los servidores deben estar definidos

Ejemplo de código no compatible (AsyncAPI 2)

  # Noncompliant {{AAR008: Definir 'servers' es obligatorio}}
  asyncapi: '2.4.0'
  info:
    title: Swagger Petstore
    version: '1.0.0'
  channels:
    /pets: {}

Solución compatible (AsyncAPI 2)

  asyncapi: '2.4.0'
  info:
    title: Swagger Petstore
    version: '1.0.0'
  servers:
    default:
      url: 'api.example.com'
      protocol: 'https'
      description: Default server for the pet store
  channels:
    /pets: {}

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0' # Noncompliant {{AAR008: Definir 'servers' es obligatorio}}
info:
  title: Swagger Petstore
  version: '1.0.0'
channels:
  userSignup:
    address: user/signup
    messages:
      UserSignedUp:
        payload:
          type: object

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Swagger Petstore
  version: '1.0.0'
servers:
  default:
    host: 'api.example.com'
    protocol: 'wss'
    description: Default server for the pet store
channels:
  userSignup:
    address: user/signup
    messages:
      UserSignedUp:
        payload:
          type: object
