El contacto debe contener los campos name, url y email

Ejemplo de código no compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
  contact: # Noncompliant {{AAR016: El objeto 'contact' debe incluir los campos 'name', 'url' y 'email'.}}
    name: hola
channels:
  /pets: {}

Solución compatible (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
  contact:
    name: hola
    email: enrgomez2002@gmail.com
    url: https://support.example.com
channels:
  /pets: {}
