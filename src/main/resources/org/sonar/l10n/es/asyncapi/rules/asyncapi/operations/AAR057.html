Al menos un channel del documento AsyncAPI (la clave de propiedad del channel en AsyncAPI 2, o el address del channel en AsyncAPI 3) debe estar documentado como topic de error, siguiendo el patrón <topicOriginal>.[<grupo_consumo>.]error.<n> (ej.: beca.cmd.alumnos.solicitud.beca.grupo1.error.1), que Spring requiere de forma exacta para enrutar los mensajes de error.

El segmento del grupo de consumo solo forma parte del nombre cuando existe más de un consumidor del topic original. El sufijo numérico final (<n>) es obligatorio. Esta regla es una comprobación de existencia sobre todo el documento: si ningún channel coincide con el patrón, se reporta una única incidencia; los channels individuales que no coincidan no se marcan.

Ejemplo Noncompliant (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Beca API
  version: '1.0.0'
channels:
  beca.cmd.alumnos.solicitud.beca:
    subscribe:
      operationId: receiveSolicitudBeca
      message:
        payload:
          type: object

Solución Compliant (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Beca API
  version: '1.0.0'
channels:
  beca.cmd.alumnos.solicitud.beca:
    subscribe:
      operationId: receiveSolicitudBeca
      message:
        payload:
          type: object
  beca.cmd.alumnos.solicitud.beca.grupo1.error.1:
    publish:
      operationId: publishSolicitudBecaErrorGrupo1
      message:
        payload:
          type: object

Ejemplo Noncompliant (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Beca API
  version: 1.0.0
channels:
  solicitudBeca:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      SolicitudBecaMessage:
        payload:
          type: object

Solución Compliant (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Beca API
  version: 1.0.0
channels:
  solicitudBeca:
    address: beca.cmd.alumnos.solicitud.beca
    messages:
      SolicitudBecaMessage:
        payload:
          type: object
  solicitudBecaErrorGrupo1:
    address: beca.cmd.alumnos.solicitud.beca.grupo1.error.1
    messages:
      SolicitudBecaErrorMessage:
        payload:
          type: object
