Los namespaces Avro deben seguir la notación en minúsculas con puntos (ej. org.example.company). Cada segmento debe comenzar con una letra minúscula y contener solo letras minúsculas y dígitos.

Ejemplo Noncompliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: Org.Example.Orders
  fields:
    - name: id
      type: string

Solución Compliant (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string
