Los namespaces de Avro deben seguir la notación de puntos en minúsculas (por ejemplo, org.example.company). Cada segmento debe comenzar con una letra minúscula y contener únicamente letras minúsculas y dígitos.

Ejemplo de código no compatible (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: Org.Example.Orders
  fields:
    - name: id
      type: string

Solución compatible (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Ejemplo de código no compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Naming
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema: # Noncompliant {{AAR045: El namespace Avro debe estar en minúsculas y separado por puntos}}
            type: record
            name: OrderValue
            namespace: Org.Example.Orders
            fields:
              - name: id
                type: string

Solución compatible (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Naming
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema:
            type: record
            name: OrderValue
            namespace: org.example.orders
            fields:
              - name: id
                type: string
