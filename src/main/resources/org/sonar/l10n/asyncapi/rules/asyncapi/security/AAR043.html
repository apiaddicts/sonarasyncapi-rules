It is recommended to add the security scheme to be used to each channel

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API demonstrating unique operationId usage in each operation.
channels:
  /pets: # Noncompliant {{AAR043: It is recommended to add the security scheme to be used to each channel}}
    subscribe:
      operationId: getPets
      message:
        contentType: application/json
        payload:
          type: object

Compliant Solution (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API demonstrating unique operationId usage in each operation.
components:
  securitySchemes:
    apiKeyScheme:
      type: httpApiKey
      name: X-API-Key
      in: header
channels:
  /pets:
    subscribe:
      operationId: getPets
      security:
        - apiKeyScheme: []
      message:
        contentType: application/json
        payload:
          type: object

Compliant Solution (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Secure Channel
  version: '1.0.0'
servers:
  default:
    host: api.example.com
    protocol: wss
components:
  securitySchemes:
    api_key:
      type: apiKey
      in: header
      name: X-API-Key
channels:
  secureEvents:
    address: secure/events
    messages:
      Event:
        payload:
          type: object
