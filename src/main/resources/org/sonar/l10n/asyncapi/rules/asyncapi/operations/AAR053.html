The channel name — the AsyncAPI 2.x channels map key, or the AsyncAPI 3.x+ channel address field — must follow the Kafka topic naming convention:

<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]
  • Exactly 5 mandatory segments (cod_poaps, classification, domain, origin, scope), separated by dots (.).
  • An optional 6th version segment may be appended (typically only for breaking changes).
  • Each segment may contain lowercase letters and digits; hyphens (-) are allowed only as an internal separator within a segment (no leading, trailing, or doubled hyphens).
  • Underscores (_) are not allowed anywhere in the channel name.

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca_registro:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Compliant Solution (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.cmd.alumnos.registro-bonificacion.beca:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Noncompliant Code Example (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Scholarship API
  version: 1.0.0
channels:
  scholarshipRegistration:
    address: beca_registro
    messages:
      Registration:
        payload: {type: object}

Compliant Solution (AsyncAPI 3)

asyncapi: 3.0.0
info:

channels:
  scholarshipRegistration:
