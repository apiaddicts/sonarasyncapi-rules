Every operation must be identified by a name in camelCase.

In AsyncAPI 2.x that name is the operationId field of the operation. AsyncAPI 3.x removed that field, so the name is the key of the operation in the operations map.

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: My Async API
  version: '1.0.0'
channels:
  pet/created:
    subscribe:   # Noncompliant {{AAR051: The operationId must be present and follow camelCase naming convention}}
      summary: Receive pet created events.
      message:
        payload:
          type: object
  pet/updated:
    publish:
      operationId: on_pet_updated # Noncompliant {{AAR051: The operationId must be present and follow camelCase naming convention}}
      summary: Publish pet updated events.
      message:
        payload:
          type: object

Compliant Solution (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: My Async API
  version: '1.0.0'
channels:
  pet/created:
    subscribe:
      operationId: solicitarBeca
      summary: Receive pet created events.
      message:
        payload:
          type: object
  pet/updated:
    publish:
      operationId: onPetUpdated
      summary: Publish pet updated events.
      message:
        payload:
          type: object

Noncompliant Code Example (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: My Async API
  version: '1.0.0'
channels:
  petCreated:
    address: pet/created
    messages:
      PetCreated:
        payload:
          type: object
operations:
  OnPetCreated: # Noncompliant {{AAR051: The operationId must be present and follow camelCase naming convention}}
    action: receive
    channel:
      $ref: '#/channels/petCreated'
    messages:
      - $ref: '#/channels/petCreated/messages/PetCreated'
  on_pet_deleted: # Noncompliant {{AAR051: The operationId must be present and follow camelCase naming convention}}
    action: receive
    channel:
      $ref: '#/channels/petCreated'

Compliant Solution (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: My Async API
  version: '1.0.0'
channels:
  petCreated:
    address: pet/created
    messages:
      PetCreated:
        payload:
          type: object
operations:
  onPetCreated:
    action: receive
    channel:
      $ref: '#/channels/petCreated'
    messages:
      - $ref: '#/channels/petCreated/messages/PetCreated'
  onPetDeleted:
    action: receive
    channel:
      $ref: '#/channels/petCreated'
