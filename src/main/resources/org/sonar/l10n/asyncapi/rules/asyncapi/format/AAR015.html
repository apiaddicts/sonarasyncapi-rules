Api should indicate the contact in the info object

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info: # Noncompliant {{AAR015: The 'info' object must contain a 'contact' section.}}
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
channels:
  /pets: {}

Compliant Solution (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Operation ID Example API
  version: '1.0.0'
  description: API que demuestra el uso de operationId único en cada operación.
  contact:
    name: hola
    email: enrgomez2002@gmail.com
    url: https://support.example.com
channels:
  /pets: {}
