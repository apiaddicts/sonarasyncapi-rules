The namespace of a named Avro schema (record, enum or fixed) is required and must follow the corporate pattern: org.madrid.<cod_poaps>.<classification>.<domain> for application schemas, or org.madrid.common.<domain> for common schemas shared through the eda_kafka_esquemas repository. Each placeholder segment may contain lowercase letters, digits, hyphens, and underscores. A schema that omits the namespace, or whose namespace does not match the pattern, is noncompliant.

Noncompliant Code Example (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Compliant Solution (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.madrid.p001.core.orders
  fields:
    - name: id
      type: string

payload:
  type: record
  name: OrderValue
  namespace: org.madrid.common.orders
  fields:
    - name: id
      type: string
