In the Kafka context, the protocol of every server declared in the servers section must be either kafka or kafka-ssl. Any other protocol, such as https, wss or amqp, is not permitted.

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: My Async API
  version: '1.0.0'
servers:
  production:
    url: broker.example.com:9092
    protocol: https   # Noncompliant {{AAR064: The server protocol must be 'kafka' or 'kafka-ssl'}}
    description: Production server
channels:
  user-events: {}

Compliant Solution (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: My Async API
  version: '1.0.0'
servers:
  production:
    url: broker.example.com:9092
    protocol: kafka-ssl
    description: Production server
channels:
  user-events: {}
