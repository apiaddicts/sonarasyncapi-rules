The AsyncAPI document version declared in the root asyncapi field must be one of the versions allowed by the organization. The list of allowed versions is configurable through the allowedVersions parameter (a comma-separated list, for example 2.6.0,3.0.0); its default value is 2.6.0,3.0.0,3.1.0. A document whose asyncapi field is missing, null or empty is not reported by this rule.

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'   # Noncompliant {{AAR063: The asyncapi version must be one of the versions allowed by the organization}}
info:
  title: My Async API
  version: '1.0.0'
channels:
  /pets: {}

Compliant Solution (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: My Async API
  version: '1.0.0'
channels:
  /pets: {}

Noncompliant Code Example (AsyncAPI 3)

# With allowedVersions narrowed to "2.6.0", a 3.0.0 document is reported
asyncapi: '3.0.0'   # Noncompliant {{AAR063: The asyncapi version must be one of the versions allowed by the organization}}
info:
  title: My Async API
  version: '1.0.0'

Compliant Solution (AsyncAPI 3)

# 3.0.0 is part of the default allowedVersions = "2.6.0,3.0.0,3.1.0"
asyncapi: '3.0.0'
info:
  title: My Async API
  version: '1.0.0'
