The x-payload-references vendor extension links a message payload (or schema) to the Avro type that backs it in the schema registry. It can appear anywhere in the document — on a message, a payload/schema object, or elsewhere.

Whenever x-payload-references exists, it must be an array, and each item must define three required, non-empty fields, each of which must also match its expected format:

  • subject — the schema name in the registry (schema registry subject characters only: letters, digits, ., -, _ and :).
  • ref — the SVN URL of the .avsc file (an http(s), svn, svn+ssh or file URL pointing to a .avsc file, optionally followed by a revision or query suffix).
  • referenceName — the fully qualified Avro type name: a lowercase namespace followed by a capitalized type, e.g. org.madrid.core.payload.alumnos.Ciudadano.

Noncompliant Code Example (invalid field formats)

x-payload-references:
  - subject: Ciudadano
    ref: no-es-url                  # not an SVN URL pointing to a .avsc file
    referenceName: cualquier_cosa   # not a fully qualified Avro type name

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.evt.alumnos.registro-bonificacion.beca:
    subscribe:
      message:
        payload:
          type: object
        x-payload-references:
          - subject: Ciudadano
            referenceName: org.madrid.core.payload.alumnos.Ciudadano

Compliant Solution (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.evt.alumnos.registro-bonificacion.beca:
    subscribe:
      message:
        payload:
          type: object
        x-payload-references:
          - subject: Ciudadano
            ref: https://svn.example.com/schemas/avro/Ciudadano.avsc
            referenceName: org.madrid.core.payload.alumnos.Ciudadano

Noncompliant Code Example (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Scholarship API
  version: 1.0.0
channels:
  scholarshipRegistration:
    address: beca.evt.alumnos.registro-bonificacion.beca
    messages:
      Registration:
        payload: {type: object}
        x-payload-references:

Compliant Solution (AsyncAPI 3)

asyncapi: 3.0.0
info:
  title: Scholarship API
  version: 1.0.0
channels:
  scholarshipRegistration:
    address: beca.evt.alumnos.registro-bonificacion.beca

        x-payload-references:
          - subject: Ciudadano
