The name field of every Avro record must be in CamelCase with an uppercase first letter (e.g. SolicitudComunicacion, ResultadoComunicacionMail). This applies to the top-level record and to any record nested inside fields[].type (as a plain nested type, inside a union, inside an array's items, or inside a map's values). AAR048 already validates that Avro names use only valid characters, but does not enforce this casing convention.

Noncompliant Code Example (AsyncAPI 2)

payload:
  type: record
  name: SolicitudComunicacion
  namespace: org.example.orders
  fields:
    - name: resultado
      type:
        type: record
        name: resultado_comunicacion_mail # Noncompliant - nested record name is not CamelCase
        fields:
          - name: estado
            type: string

Compliant Solution (AsyncAPI 2)

payload:
  type: record
  name: SolicitudComunicacion
  namespace: org.example.orders
  fields:
    - name: resultado
      type:
        type: record
        name: ResultadoComunicacionMail
        fields:
          - name: estado
            type: string
