It is recommended to have a unique identifier per message

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Unique Identifier per Message Example API
  version: '1.0.0'
  description: API de ejemplo que incluye identificadores únicos para cada mensaje.
channels:
  /order:
    description: Canal para enviar y recibir información de pedidos.
    publish:
      operationId: sendOrder
      message: #Noncompliant {{AAR042: It is recommended to have a unique identifier per message}}
        contentType: application/json
        payload:
          type: object
          properties:
            orderId:
              type: string
              description: ID único del pedido.
            product:
              type: string
              description: Nombre del producto.
            quantity:
              type: integer
              description: Cantidad del producto pedido.
    subscribe:
      operationId: receiveOrderConfirmation
      message:
        messageId: orderConfirmationMessage
        contentType: application/json
        payload:
          type: object
          properties:
            orderId:
              type: string
              description: ID único del pedido.
            status:
              type: string
              description: Estado de la confirmación del pedido.

Compliant Solution (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Message Identifier Avro Example API
  version: 1.0.0
servers:
  production:
    host: api.example.com
    protocol: kafka
channels:
  carga:
    address: carga
    messages:
      CargaMessage:
        messageId: cargaEvent
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema:
            type: record
            name: CargaValue
            namespace: com.example.avro
            fields:
              - name: id
                type: string
