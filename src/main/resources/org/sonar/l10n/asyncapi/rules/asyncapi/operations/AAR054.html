The channel name — the AsyncAPI 2.x channels map key, or the AsyncAPI 3.x+ channel address field — follows the corporate naming pattern:

<cod_poaps>.<classification>.<domain>.<origin>.<scope>[.<version>]

The second segment (classification) must be one of:

  • cdc — Change Data Capture.
  • cmd — Command that triggers a modification in the domain.
  • sys — Internal system topic, not intended for public consumption.

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.evt.alumnos.registro-bonificacion.beca:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Compliant Solution (AsyncAPI 2)

asyncapi: '2.6.0'
info:
  title: Scholarship API
  version: '1.0.0'
channels:
  beca.cmd.alumnos.registro-bonificacion.beca:
    subscribe:
      operationId: receiveRegistration
      message:
        payload:
          type: object

Noncompliant Code Example (AsyncAPI 3)

asyncapi: 3.0.0
info:

channels:
  scholarshipRegistration:

    messages:

Compliant Solution (AsyncAPI 3)

asyncapi: 3.0.0
