The security scheme must be among those allowed by the organization and must be complete

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Security Scheme Example API
  version: '1.0.0'
components:
  securitySchemes:
    mainAuth: # Noncompliant {{AAR018: The security scheme must be among those allowed by the organization and must be complete}}
      type: http
channels:
  /secure-data: {}

Compliant Solution (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Security Scheme Example API
  version: '1.0.0'
components:
  securitySchemes:
    mainAuth:
      type: oauth2
      flows:
        authorizationCode:
          authorizationUrl: https://example.com/oauth/authorize
          tokenUrl: https://example.com/oauth/token
          scopes:
            read: Grants read access
channels:
  /secure-data: {}
