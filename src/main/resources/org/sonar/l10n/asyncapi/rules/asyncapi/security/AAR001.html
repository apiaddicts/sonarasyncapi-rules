For security reasons, servers must use a secure protocol (such as https, wss, amqps).

Noncompliant Code Example (AsyncAPI 2)

  asyncapi: '2.4.0'
  info:
    title: Swagger Petstore
    version: '1.0.0'
  servers:
    default:
      url: 'api.example.com'
      protocol: 'http' # Noncompliant {{AAR001: Server must use a secure protocol (https, wss, amqps, etc).}}
      description: Default server for the pet store
  channels:
    /pets: {}

Compliant Solution (AsyncAPI 2)

  asyncapi: '2.4.0'
  info:
    title: Swagger Petstore
    version: '1.0.0'
  servers:
    default:
      url: 'api.example.com'
      protocol: 'https'
      description: Default server for the pet store
  channels:
    /pets: {}
