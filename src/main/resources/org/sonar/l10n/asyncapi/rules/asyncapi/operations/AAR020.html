Specify a unique identifier for the AsyncAPI document

Noncompliant Code Example (AsyncAPI 2)

asyncapi: "2.0.0" # Noncompliant {{AAR020: Specify a unique identifier for the AsyncAPI document}}
info:
  title: Awesome API
  description: A very well-defined API
  version: "1.0"
servers:
  production:
    url: "stoplight.io"
    protocol: "https"

  hello:

Compliant Solution (AsyncAPI 2)

  title: Awesome API
  description: A very well-defined API
  version: "1.0"
servers:
  production:
    url: "stoplight.io"
    protocol: "https"
channels:
  hello:
    servers: production
