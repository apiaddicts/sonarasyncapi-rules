You should categorize the operations of your contract with tags. Categorizing operations helps your users understand the broad organization of the API and highlights the type of manipulated resources.

Noncompliant Code Example (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Swagger Petstore
  version: '1.0.0'
servers:
  production:
    url: 'https://api.petstore.com'
    protocol: 'https'
    description: Servidor de producción para la API de la tienda de mascotas
channels:
    /pets:
      description: Canal de comunicación para operaciones relacionadas con mascotas
      subscribe: # Noncompliant {{AAR009: Operation must declare at least one tag.}}
        operationId: receivePets
        summary: Operación para recibir la lista de mascotas
        message:
          contentType: application/json
          payload:
            type: array
            items:
              type: object
              properties:
                id:
                  type: string
                  description: ID de la mascota
                name:
                  type: string
                  description: Nombre de la mascota

Compliant Solution (AsyncAPI 2)

asyncapi: '2.4.0'
info:
  title: Swagger Petstore
  version: '1.0.0'
servers:
  production:
    url: 'https://api.petstore.com'
    protocol: 'https'
    description: Servidor de producción para la API de la tienda de mascotas
channels:
  /pets:
    description: Canal de comunicación para operaciones relacionadas con mascotas
    subscribe:
      operationId: receivePets
      tags:
        - name: used-tag
      summary: Operación para recibir la lista de mascotas
      message:
        contentType: application/json
        payload:
          type: array
          items:
            type: object
            properties:
              id:
                type: string
                description: ID de la mascota
              name:
                type: string
                description: Nombre de la mascota

Noncompliant Code Example (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: AsyncAPI Example
  version: '1.0.0'
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  user-signup:
    address: user/signup
    messages:
      UserSignedUp:
        payload:
          type: object
operations:
  UserSignup: # Noncompliant {{AAR009: Operation must declare at least one tag.}}
    action: send
    channel:
      $ref: '#/channels/user-signup'
    messages:
      - $ref: '#/channels/user-signup/messages/UserSignedUp'

Compliant Solution (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: AsyncAPI Example
  version: '1.0.0'
servers:
  production:
    host: api.example.com
    protocol: wss
channels:
  user-signup:
    address: user/signup
    messages:
      UserSignedUp:
        payload:
          type: object
operations:
  UserSignup:
    action: send
    channel:
      $ref: '#/channels/user-signup'
    messages:
      - $ref: '#/channels/user-signup/messages/UserSignedUp'
    tags:
      - name: users
