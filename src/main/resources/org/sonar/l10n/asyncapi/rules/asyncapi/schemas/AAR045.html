Avro namespaces must follow lowercase dot notation (e.g. org.example.company). Each segment must start with a lowercase letter and contain only lowercase letters and digits.

Noncompliant Code Example (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: Org.Example.Orders
  fields:
    - name: id
      type: string

Compliant Solution (AsyncAPI 2)

payload:
  type: record
  name: OrderValue
  namespace: org.example.orders
  fields:
    - name: id
      type: string

Noncompliant Code Example (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Naming
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema: # Noncompliant {{AAR045: Avro namespace must be lowercase and separated by dots}}
            type: record
            name: OrderValue
            namespace: Org.Example.Orders
            fields:
              - name: id
                type: string

Compliant Solution (AsyncAPI 3)

asyncapi: '3.0.0'
info:
  title: Avro Namespace Naming
  version: 1.0.0
channels:
  orders:
    address: orders
    messages:
      OrderMessage:
        payload:
          schemaFormat: 'application/vnd.apache.avro;version=1.9.0'
          schema:
            type: record
            name: OrderValue
            namespace: org.example.orders
            fields:
              - name: id
                type: string
